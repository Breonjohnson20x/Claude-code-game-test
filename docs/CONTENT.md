## The five-turn arc

Source: `src/game/content/crises.js` (`turn1` … `turn5`, `getCrisis`). Categories: `diplomacy` = Diplomacy, `military` = Military, `clandestine` = Clandestine, `research` = Research / Magic, `economic` = Economic / Infrastructure.
Each order lists its cost, the Council's reactions, its text, the outcome lines shown after it resolves, and its
effects. The resolver also applies economy, threads, events and intensity on top (see GAME_GUIDE.md).
Canonical path: order **E** on turn 1, **A** on turns 2–5. Orders shown are those offered on that path; some
labels, warnings and effects change with flags (for example the Accord, an exposed general, a broken oath).

## Deployments

Offered on the Resolution screen by `deploymentOffers(state)` in `src/game/content/expedition.js`:

| Kind | Beats | When offered |
|---|---|---|
| `march` | road → checkpoint → wilds → ruin → champion → camp | turns 1–4, until the march of this reign is done |

## How to add content

- **A new order or a changed one:** edit the turn builder in `src/game/content/crises.js`. Orders are data:
  `{ id, category, label, text, cost, reactions, warning?, effects, outcome, voices }`. Effects use the helpers in
  `src/game/content/effectHelpers.js` (`res`, `rel`, `fac`, `flag`, `counter`, `thread`, `region`, `heat`, `chron`, `mem`,
  `voice`, `character`). Keep one order per category per turn (custom decrees blend orders by category).
- **A march beat or choice:** add a builder in `src/game/content/expedition.js`, register it in `BEATS`, and add its id
  to `EXPEDITION_KINDS`. Add a scenario in `src/game/dev/scenarios.js` so the e2e sweep shows it.
- **A campfire scene:** add it to `SCENES` in `src/game/content/campfire.js` and to `sceneSpeaker`'s selection.
- **A Legacy:** add it to `LEGACIES` with an `earn` text and a `check(state)`, then apply its effect where it matters
  (`cycle/passing.js` `beginNextCycle`, `sim/resolver.js`, the duel engine via `modifiers.legacies`).
- Then: `npm test`, `npm run docs:content`, `npm run e2e`.
